# Pandas for AI/ML – Technical Assessment

This repository contains my Pandas assignment completed as part of my AI/ML learning journey.

The assignment focuses on Pandas and NumPy concepts related to data manipulation, analysis, debugging, preprocessing, and data cleaning.

## 📌 Assignment Overview

The assignment is divided into four sections:

- **Section A – Output Prediction**
- **Section B – Code Correction**
- **Section C – Edge Cases**
- **Section D – Scenario-Based Questions**

## 📂 Repository Contents

- `Hima_Pandas.ipynb` – Complete Jupyter Notebook containing the assignment
- `student_assessment_dirty.csv` – Dataset used for the data-cleaning task
- `README.md` – Repository documentation

## 🧠 Topics Covered

### Section A – Output Prediction

- NumPy arrays and Pandas Series
- Vectorized operations
- Boolean filtering
- Descriptive statistics
- Group-wise analysis
- Positive and negative correlation

### Section B – Code Correction

- Reading CSV files
- Sorting data
- Handling missing values
- Calculating correlation
- Identifying and correcting errors in Pandas code

### Section C – Edge Cases

- NumPy broadcasting
- CSV parsing
- Missing values
- Date conversion
- Numeric conversion
- Outlier analysis
- Mean and median
- Invalid values

### Section D – Scenario-Based Data Cleaning

The dataset contains different data-quality issues such as:

- Missing marks
- Duplicate records
- Inconsistent department names
- Text values in the Marks column
- `Absent` and `NA` values
- Marks outside the valid 0–100 range

The cleaning process includes:

1. Loading and inspecting the dataset
2. Checking missing values
3. Standardizing department names
4. Removing duplicate records
5. Converting marks into numeric format
6. Handling missing and non-numeric values
7. Identifying invalid marks
8. Displaying the cleaned dataset
9. Reporting the cleaning results
